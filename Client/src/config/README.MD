# src/config/routes.js

File này lưu toàn bộ **đường dẫn (path)** của ứng dụng dưới dạng một object duy nhất,  
giúp việc quản lý và thay đổi route tập trung, tránh viết path rải rác khắp code.

## Nội dung hiện tại

```js
const routes = {
    home: '/',// mẫu
    ... //viết tiếp ở đây
};
export default routes;
```
